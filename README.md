# 🕵️‍♂️ Burp Suite Certified Practitioner Cheat Sheet (Conan)

Welcome to **Conan**, a comprehensive cheat sheet and methodology guide designed specifically to help you conquer the **Burp Suite Certified Practitioner (BSCP)** exam. 

Whether you are navigating the PortSwigger Web Security Academy labs or preparing for the final certification attempt, this repository serves as a centralized, quick-reference repository for payloads, bypass techniques, and exploitation strategies.

## 🎯 Purpose
The BSCP exam is entirely hands-on and strictly time-boxed. Success requires not just knowing the vulnerabilities, but having the right payloads and methodologies at your fingertips. "Conan" is built to eliminate guesswork and speed up your exploitation process during the exam.

## 📚 What's Inside?
This cheat sheet is categorized by the core vulnerability classes tested in the BSCP exam:

* **Client-Side Vulnerabilities:**
  * Cross-Site Scripting (XSS)
  * Cross-Site Request Forgery (CSRF)
  * Cross-Origin Resource Sharing (CORS)
  * Clickjacking
* **Server-Side Vulnerabilities:**
  * SQL Injection (SQLi)
  * Server-Side Request Forgery (SSRF)
  * OS Command Injection
  * Directory Traversal
  * Access Control Vulnerabilities
* **Advanced Exploitation:**
  * Insecure Deserialization
  * Web Cache Poisoning
  * HTTP Host Header Attacks
  * Request Smuggling
  * XML External Entity (XXE) Injection

## 🚀 How to Use This Guide
1. **Pre-Exam:** Use the checklists to ensure you have a solid methodology for identifying each vulnerability class.
2. **During the Exam:** Use the `[Ctrl + F]` friendly layout to quickly search for specific payloads (e.g., "Blind SSRF out-of-band", "XSS WAF bypass").
3. **Practice:** Apply these techniques directly to the PortSwigger Web Security Academy mystery labs.

This repository is created for educational purposes and certification preparation only. All payloads and techniques should only be used on authorized systems, such as the PortSwigger Web Security Academy labs or during the official BSCP exam.
